# CNC Master Android

Aplicativo Android independente para treinamento prático de torno CNC Fanuc.

## Compilar APK
O workflow **Build CNC Master APK** compila o APK de depuração e publica o arquivo como artefato do GitHub Actions.

O APK desta primeira versão é destinado a instalação e testes. Ainda não é uma versão assinada para distribuição na Play Store.

## Conteúdo inicial
- Identidade visual preta e dourada.
- Trilha intermediária de torno CNC Fanuc.
- Editor didático de blocos e verificações básicas.
- Biblioteca inicial de códigos G.
- Avisos de segurança para validar programas na máquina real.

O projeto fica isolado na pasta `cnc-master/`; os arquivos do projeto BeardedBR e do CNC Assistente não são modificados.
